視覚解説：ガソリン価格のパラドックス

Page 1：イントロダクション

「1ヶ月前の安い原油」を売っているはずなのに、なぜ「今日のニュース」で価格が上がるのか？物理的なモノの流れと、経済的な価値の決まり方のギャップを解明します。

Page 2：直感と現実の矛盾

消費者の「安く仕入れた分は安く売るべき」という直感と、ニュースに即座に反応する市場の動きの対立を示しています。この「物理的タイムラグ」vs「経済的即時性」こそが最大の謎です。

Page 3：物理的実態（1.5ヶ月の旅）

中東から日本へ、タンカー移動と精製を経て届くまでには約6週間の時間がかかります。つまり、「今のガソリンは過去の産物」であるという認識は物理的には100%正しいのです。

Page 4：経済的真実（再調達原価）

価格決定の鍵は「再調達原価」です。安く売り続けて仕入れ資金が足りなくなれば供給が止まってしまいます。システムを維持するためには、「未来の仕入れ値」で売る必要があります。

Page 5：情報レイヤーの即時性

時速30kmで動くタンカーに対し、電子取引の「情報」は光速で移動します。石油が国際商品である以上、将来の供給リスクという情報はタンカーの到着を待たずに価格に反映されます。

Page 6：国内価格の伝達装置

日本の卸価格（仕切価格）は、毎週水曜日に元売りからスタンドへ通知されます。この週次の改定サイクルが、国際価格の変動を国内の店頭へと迅速に橋渡ししています。

Page 7：70日分備蓄の裏事情

元売り会社には70日分以上の備蓄義務があります。価格上昇局面では莫大な「在庫評価益」が出ますが、これは次回の高価な原油を買うための原資となり、実際の現金利益とは異なります。

Page 8：スタンドの極限マージン

ガソリンスタンドの粗利は1リットル数円と極めて薄いです。仕入れ価格が3円上がった時に据え置けば、即座に「逆ザヤ」で赤字になるため、看板の書き換えは生存本能と言えます。

Page 9：上がる時はロケット、下がる時は羽根

価格改定の心理的・経営的バイアスを解説。上昇時は赤字回避のために即座に上げ、下降時は高値在庫のコスト回収のために下がり方が緩やかになる傾向があります。

Page 10：価格の半分は固定税金

ガソリン価格の約半分は固定税金です。原油価格が半値になってもガソリンが半値にならないのは、この「動かない部分（固定レイヤー）」が大きな割合を占めているからです。

Page 11：激変緩和措置とタイムラグ

政府の補助金は急激な価格高騰を抑える防波堤ですが、これも週次サイクルのため、急激なショック直後には補助の増額が追いつかず、一時的な値上がりが発生します。

Page 12：統合されたシステムの出力

国際市場、国の制度、卸売、小売、税制。これら5つの異なる力学と時間軸が衝突し、統合された結果が、私たちが目にする今日の店頭価格なのです。

Page 13：二つの時計のズレを識る

物理的な「遅い時計」と、将来コストの「速い時計」。この不一致を理解することが、将来的に変動性が高まるエネルギー市場を読み解く鍵となります。
